# محاسبة النفس

تطبيق ويب (PWA) يومي لمحاسبة النفس على منهج الإمام الغزالي في المراقبة والمحاسبة.

## المزايا

- **المقامات الستة:** المشارطة، المراقبة، المحاسبة، المعاقبة، المجاهدة، المعاتبة.
- **سجل يومي:** خزائن الساعات الـ24، الدواوين الثلاثة (لِمَ، كيف، لِمَنْ).
- **مكتبة الدرر:** آيات وأحاديث وآثار وقصص ومناجاة.
- **تذكيرات:** مشارطة الصباح ومحاسبة المساء.
- **تخزين محلي فقط:** لا خادم، لا تتبّع، لا حسابات.
- **تصدير واستيراد:** نسخة احتياطية بصيغة JSON.
